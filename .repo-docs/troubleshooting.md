# Troubleshooting

## Do NOT

- **Do not edit files in `docs/Browse/`, `docs/Read/`, `docs/Full Book/`, or `docs/Bestiary/` directly.** These are regenerated by `just update` and your changes will be overwritten. Use `static_content/` for persistent overrides.
- **Do not edit the `gh-pages` branch.** It is force-pushed by CI on every deploy.
- **Do not remove the `DATA_VERSION` placeholder from `mkdocs.yml`.** The `just update` recipe replaces it with the upstream commit info. If it's missing, the version stamp breaks. The `clean_docs` recipe restores the placeholder.
- **Do not run `just update` with uncommitted changes to `mkdocs.yml`.** The recipe modifies `mkdocs.yml` in-place (replaces `DATA_VERSION`), and `clean_docs` resets it. Uncommitted changes in that file may be lost.

## Known Issues

- **Bestiary: unordered chapters and broken links.** The Bestiary section is work-in-progress. Some chapter ordering is off and internal links may not resolve.
- **Full Book page is slow to load.** The entire rulebook on a single page is heavy. This is by design for Ctrl+F use, but expect multi-second load times.
- **No automated tests.** There is no test suite. Verification is manual: run `mkdocs build --strict` and check the dev server.

## Common Errors

### `just update` fails with git clone error

**Cause:** SSH key not configured for GitHub, or `data-md-linked` repo not accessible.

**Fix:** Ensure your SSH key is added to GitHub and you have access to the SteelCompendium org.

### MkDocs build warnings about broken links

**Cause:** Upstream content links reference files that don't exist after restructuring, or `REL_PATH_PREFIX` replacement didn't match.

**Fix:** Check the `justfile` sed/perl replacement logic. Run `mkdocs build --strict` to see all warnings. The link-fixing section of the update recipe may need adjustment for new upstream link patterns.

### Search returns no results for a page you can see

**Cause:** The page has `search: exclude: true` in its YAML front matter. This is intentional for Read and Full Book sections.

**Fix:** If the page should be searchable, check that it's in the Browse section, not Read or Full Book.

### `clean_docs` leaves stale files

**Cause:** `clean_docs` preserves `javascripts/`, `stylesheets/`, `Media/`, `index.md`, `preferences.md`, and `.nav.yml`. Everything else is deleted.

**Fix:** If new persistent directories are added to `docs/`, update the exclusion list in `justfile`'s `clean_docs` recipe.

### Font preferences not applying

**Cause:** The `overrides/main.html` script reads from `localStorage` key `mkdocs:fontPrefs`. If localStorage is cleared or blocked, preferences reset.

**Fix:** Check browser developer tools > Application > Local Storage for the `mkdocs:fontPrefs` key.
