# Steel Compendium v2

MkDocs Material site for the Draw Steel TTRPG rules reference at steelcompendium.io/v2.

## Key Rules

- **Never edit generated content directly.** Files under `docs/Browse/`, `docs/Read/`, `docs/Full Book/`, and `docs/Bestiary/` are wiped and regenerated by `just update`. To override a generated page, place your version at the same relative path under `static_content/docs/`.
- **Safe to edit:** `docs/javascripts/`, `docs/stylesheets/`, `overrides/`, `scripts/`, `static_content/`, `mkdocs.yml`, `justfile`.
- **Content source:** All rules markdown comes from `data-md-linked` (branch v3). This repo only handles presentation.

## Repository Documentation

This repo uses standardized `.repo-docs/` documentation. **Read `.repo-docs/index.md` first** -- it contains the reading guide, role-based routing, and links to all other docs.
