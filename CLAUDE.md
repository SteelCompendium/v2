# Steel Compendium v2

MkDocs Material site for the Draw Steel TTRPG rules reference at steelcompendium.io/v2.

## Key Rules

- **Never edit generated content directly.** Files under `docs/Browse/`, `docs/Read/`, and `docs/scc/` are wiped and regenerated by `steel-etl site`. To override a generated page, place your version at the same relative path under `static_content/docs/`.
- **Safe to edit:** `docs/javascripts/`, `docs/stylesheets/`, `overrides/`, `scripts/`, `static_content/`, `mkdocs.yml`, `site.yaml`.
- **Content source:** All rules markdown is generated by `steel-etl` from annotated source markdown. The workspace `just deploy-v2` recipe runs `steel-etl gen` (pipeline) then `steel-etl site` (MkDocs mapping). `docs/Browse/*` and `docs/Read/chapter/*` are full book-order subtree renders — each page is a direct section-mapped render of its source section's subtree produced by `RenderSubtree` (no composite reassembly step). Static overrides in `static_content/` are applied last and take precedence over generated pages. See `site.yaml` for section and group configuration.

## Repository Documentation

This repo uses standardized `.repo-docs/` documentation. **Read `.repo-docs/index.md` first** -- it contains the reading guide, role-based routing, and links to all other docs.
