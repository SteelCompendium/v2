# Traits

---

Many creatures have [traits](monster-trait.md), which are features that don't require a main action, a maneuver, or a [triggered action](../combat/triggered-action.md) to activate, such as the Crafty trait possessed by many goblins. (Chapter 10: Combat in *Draw Steel: Heroes* talks about action types.)
