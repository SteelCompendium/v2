# Project Points

---

Some careers provide [project points](project-points.md) you can put toward crafting and [research projects](research-project.md) (see Chapter 12: [Downtime Projects](../../../Read/heroes/downtime-projects.md)). These [project points](project-points.md) can be divided among multiple projects, but they can't be used more than once. You must meet the other prerequisites for a project to start it, as usual.

At the Director's discretion, your career might also let you start the game with the materials needed for one or more projects, so you can immediately put your [project points](project-points.md) toward those projects—possibly before the adventure begins! This is especially useful for characters who are going on only one adventure. Otherwise, you can hold onto the points and spend them once you do start a project.
