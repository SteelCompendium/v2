<div class="pj__prose">
<p>When you complete this project, you end up with a 3-square-by-3 square <a href="../movement/teleport/">teleport</a>ation platform activated by a <a href="../rule/general/supernatural/">supernatural</a> password. The platform is permanently affixed to the ground in the location where you create it. Any creature with the password can use the <a href="../movement/teleport/">teleport</a>ation platform to instantly <a href="../movement/teleport/">teleport</a> any creatures or objects on the platform to a location they know, including another <a href="../movement/teleport/">teleport</a>ation platform whose <a href="../rule/general/supernatural/">supernatural</a> password they know. You and any creature you designate upon completion of the activity can change the password as a <a href="../rule/resource/respite/">respite</a> activity.</p>
<p>Each time the <a href="../movement/teleport/">teleport</a>ation platform is used, the chance of it malfunctioning and <a href="../movement/teleport/">teleporting</a> creatures or objects on it to a random platform increases by 1 percent (to a maximum of 50 percent). You can restore the platform back to its original <a href="../rule/combat/condition/">condition</a> and reset this chance of malfunction as a <a href="../rule/resource/respite/">respite</a> activity.</p>
