inside the host's body.

After 1d3 + 1 weeks of gestation, the handmaiden fully forms inside the host. The handmaiden always moves with and occupies the same space as the host and can't be separated from them. While totally within the creature, the handmaiden doesn't have <a class="sb-term" href="../../../../rule/combat/line-of-effect/">line of effect</a> to the host or targets outside the host and vice versa. As a maneuver, the handmaiden can emerge from the host as a horrifying tower of flesh and bone that remains attached to the host's insides. While emerged, the handmaiden can use a move action to make the host move up to their speed and has access to the host's <a class="sb-term" href="../../../../rule/combat/signature-ability/">signature abilities</a>, using the host's modifiers for any power rolls. The handmaiden has the same <a class="sb-term" href="../../../../rule/character/stability/">Stability</a> as the host. If the handmaiden or host is <a class="sb-term" href="../../../../movement/forced-movement/">force moved</a>, the other moves with them. While emerged, the handmaiden can be targeted independently of the host. The handmaiden can retreat totally within the host's body as a maneuver. If the handmaiden dies, their remains separate from the host.

The <a class="sb-term" href="../../../../project/find-a-cure/">Find a Cure</a> downtime project in Draw Steel: Heroes can be used to find a cure that removes a handmaiden from a host.
