# Make or Assist a Test

---

<section class="sc-trait sc-trait--crest sc-trait--lead" data-action="trait">
<header class="sc-trait__head">
<span class="sc-crest sc-trait__crest"><span class="sc-trait__glyph">*</span></span>
<div class="sc-trait__titles">
<div class="sc-trait__eyebrow"><span class="sc-trait__dia"></span>Feature</div>
<h3 class="sc-trait__name">Make or Assist a Test</h3>
</div>
</header>
<div class="sc-trait__body">
<p>Many <a href="../../../../rule/test/test/">tests</a> are maneuvers if made in combat. Searching a chest with a <a href="../../../../rule/character/reason/">Reason</a> <a href="../../../../rule/test/test/">test</a>, picking a door&#39;s lock with an <a href="../../../../rule/character/agility/">Agility</a> <a href="../../../../rule/test/test/">test</a>, or lifting a portcullis with a <a href="../../../../rule/character/might/">Might</a> <a href="../../../../rule/test/test/">test</a> would all be maneuvers. Assisting a <a href="../../../../rule/test/test/">test</a> is also a maneuver in combat (see Assist a <a href="../../../../rule/test/test/">Test</a> in Chapter 9: <a href="../../../../../Read/heroes/tests/">Tests</a>).</p>
<p>Complex or time-consuming <a href="../../../../rule/test/test/">tests</a> might require a main action if made in combat—or could take so long that they can&#39;t be made during combat at all. Other <a href="../../../../rule/test/test/">tests</a> that take no time at all, such as a <a href="../../../../rule/character/reason/">Reason</a> <a href="../../../../rule/test/test/">test</a> to recall lore about mummies, are usually <a href="../../../../rule/combat/free-maneuver/">free maneuvers</a> in combat. The Director has the final say regarding which <a href="../../../../rule/test/test/">tests</a> can be made as maneuvers.</p>
</div>
</section>
