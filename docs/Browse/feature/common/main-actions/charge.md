# Charge

---

<section class="sc-trait sc-trait--crest sc-trait--lead" data-action="trait">
<header class="sc-head"><div class="sc-head__stack"><span class="sc-crest sc-trait__crest"><span class="sc-trait__glyph">*</span></span>
<div class="sc-head__col sc-head__col--left"><div class="sc-head__slot sc-head__left-eyebrow sc-head__slot--line">Feature</div><h3 class="sc-head__slot sc-head__left-primary sc-head__slot--line">Charge</h3></div></div><div class="sc-head__rail sc-head__col--right"></div></header>
<div class="sc-trait__body">
<p>When a creature takes the <a href="../charge/">Charge</a> main action, they move up to their <a href="../../../../rule/character/speed/">speed</a> in a straight line, then make a <a href="../../../../rule/combat/melee/">melee</a> <a href="../free-strike/">free strike</a> (see <a href="../free-strike/">Free Strikes</a> below) against a target when they end their move. If the creature has an ability with the Charge keyword, they can use that ability against the target instead of a <a href="../free-strike/">free strike</a>.</p>
<p>A creature can&#39;t move through <a href="../../../../movement/difficult-terrain/">difficult terrain</a> or <a href="../../../../movement/shifting/">shift</a> when they charge. They can <a href="../../../../movement/fly/">fly</a> or <a href="../../../../movement/burrow/">burrow</a> as part of the <a href="../charge/">Charge</a> main action if they have that movement available to them, but they can&#39;t climb or swim while charging unless they can automatically use that movement at full <a href="../../../../rule/character/speed/">speed</a>.</p>
</div>
</section>
