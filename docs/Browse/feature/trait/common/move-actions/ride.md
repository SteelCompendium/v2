# Ride

---

<section class="sc-trait sc-trait--crest sc-trait--lead" data-action="trait">
<header class="sc-trait__head">

<h3 class="sc-trait__name">Ride</h3>
</div>
</header>
<div class="sc-trait__body">
<p>A creature can take the <a href="../ride/">Ride</a> move action only while mounted on another creature (see Mounted Combat below). When a creature takes the <a href="../ride/">Ride</a> move action, they cause their mount to move up to the mount&#39;s speed, taking the rider with them. Alternatively, a creature can use the <a href="../ride/">Ride</a> move action to have their mount use the <a href="../disengage/">Disengage</a> move action as a free triggered action. A creature can use the <a href="../ride/">Ride</a> move action only once per round. A mounted creature can only have this move action applied to them once per round. This movement can be broken up with the rider&#39;s maneuver and main action however they wish.</p>
</div>
