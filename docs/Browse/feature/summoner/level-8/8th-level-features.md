<header class="sc-trait__head">
<div class="sc-trait__titles">
<h3 class="sc-trait__name">Abyssal Evolution</h3>
</div>
<div class="sc-trait__tag">Level <span class="num">8</span></div>
</header>
<div class="sc-trait__body">
<p>At the start of each of your <a href="../../../../rule/combat/turn/">turns</a>, you can transform up to two of your demon minions within your Summoner&#39;s Range. A demon can transform into a different demon minion within your Summoner&#39;s Range, maintaining their current <a href="../../../../rule/health/stamina/">Stamina</a>. Starting from <a href="../../../../rule/combat/combat-round/">round</a> 2, a demon can transform any demon minion you can call forth for half the essence cost, as if you summoned the new minion into the demon&#39;s space.</p>
<p>The minions must be reassigned to a new squad if their new name differs from the other squad members.</p>
</div>

<section class="sc-trait" data-action="trait">
<header class="sc-trait__head">
<div class="sc-trait__titles">
<h3 class="sc-trait__name">Portfolio Champion</h3>
</div>
<div class="sc-trait__tag">Level <span class="num">8</span></div>
</header>
<div class="sc-trait__body">
<p class="sc-trait__leadin"><span class="sc-trait__dia"></span>Your circle now allows you to add a champion to your portfolio. Champions follow the same rules as your other minions, with the following exceptions:</p>
<ul><li>You can only summon and command one instance of your champion.</li><li>Your champion is in their own squad that does not count toward your maximum number of squads.</li><li>Your champion can regain <a href="../../../../rule/health/stamina/">Stamina</a> and gain <a href="../../../../rule/health/temporary-stamina/">temporary Stamina</a>.</li><li>Your champion uses your <a href="../../../../rule/health/recoveries/">Recoveries</a> to regain <a href="../../../../rule/health/stamina/">Stamina</a>.</li><li>Your champion can take the <a href="../../../common/main-actions/heal/">Heal</a> and <a href="../../../common/main-actions/defend/">Defend</a> Actions.</li><li>Your champion uses the normal rules for maneuvers.</li><li>You have an <a href="../../../../rule/dice/edge/">edge</a> whenever you use an ability with the Champion keyword from your Champion&#39;s space.</li><li>Your champion refuses to be referred to as a minion.</li></ul>
<p>After summoning a champion, you can&#39;t summon them again until you earn a <a href="../../../../rule/resource/victories/">Victory</a>.</p>
<p>Your champion gains additional features at 10th level. This includes a special Champion Action ability that costs eidos to use (see <a href="../../level-10/eidos/">Eidos</a>). This ability can be activated once per encounter at the end of any other creature&#39;s <a href="../../../../rule/combat/turn/">turn</a>.</p>
