# Wood Wise

---

When you make a [test](../rule/test/test.md) using a skill from the [exploration skill group](../skill/exploration/index.md) and at least one of the d10s rolled is a 1, you can reroll one d10. You can use this perk only once per [test](../rule/test/test.md).
