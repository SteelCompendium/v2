# Power Player

---

Whenever you make a test that uses the [Brag](../skill/brag.md), [Flirt](../skill/flirt.md), or [Intimidate](../skill/intimidate.md) skills, you can use [Might](../rule/character/might.md) instead of any other [characteristic](../rule/character/characteristic.md) the test calls for.
