# Pardon My Friend

---

When an ally within 5 squares fails a [Presence](../rule/character/presence.md) test, you can step in and make a [Presence](../rule/character/presence.md) test that takes a [bane](../rule/dice/bane.md), with your roll replacing the ally's roll. This perk can be used only once per test, even if more than one character has it.
