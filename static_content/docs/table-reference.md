# Table Reference

The rules you reach for mid-encounter — each entry links to the full rule.
Print this page for a one-sheet GM screen. *(One-liners are paraphrases —
click through for the exact rule text.)*

## Your Turn

On your turn you get **one main action, one [maneuver](Browse/feature/common/maneuvers/index.md),
and one [move action](Browse/movement/index.md)** — in any order.
[Triggered actions](Browse/rule/combat/triggered-action.md) happen off-turn;
free triggered actions and [free maneuvers](Browse/rule/combat/free-maneuver.md)
don't spend your normal allotment. Your
[heroic resource](Browse/rule/resource/heroic-resource.md) builds every turn — spend it.

## The Power Roll

**2d10 + characteristic** → three [tiers](Browse/rule/dice/tier-outcome.md):

| Roll | Tier |
|---|---|
| ≤ 11 | Tier 1 (weakest) |
| 12–16 | Tier 2 |
| 17 + | Tier 3 (strongest) |

- An [edge](Browse/rule/dice/edge.md) adds +2; a [bane](Browse/rule/dice/bane.md) −2.
- A **double edge / double bane** moves the result one tier up/down instead.
- A [natural 19–20](Browse/rule/dice/natural-19-20.md) is a critical: automatic
  tier 3 and you can take an extra main action.
- Tests use the same roll — see [test difficulty](Browse/rule/test/test-difficulty.md).

## Conditions

| Condition | In one line |
|---|---|
| [Bleeding](Browse/condition/bleeding.md) | Lose 1d6 + level Stamina after each main action, triggered action, or Might/Agility roll. |
| [Dazed](Browse/condition/dazed.md) | One thing per turn (main action *or* maneuver *or* move); no triggered actions. |
| [Frightened](Browse/condition/frightened.md) | Bane vs the source; the source has edge vs you; can't willingly move closer to it. |
| [Grabbed](Browse/condition/grabbed.md) | Speed 0; only the grabber can force-move you; bane on abilities that don't target the grabber. |
| [Prone](Browse/condition/prone.md) | Your strikes take a bane; melee vs you has edge; crawl (+1 square per square). |
| [Restrained](Browse/condition/restrained.md) | Speed 0, no Stand Up, can't be force-moved; bane on ability rolls and M/A tests; abilities vs you have edge. |
| [Slowed](Browse/condition/slowed.md) | Speed 2; can't shift. |
| [Taunted](Browse/condition/taunted.md) | Double bane on abilities that don't target the taunter (while you have line of effect to them). |
| [Weakened](Browse/condition/weakened.md) | Bane on power rolls. |

## Stamina, Dying & Recovery

- [Winded](Browse/rule/health/winded.md): at or below half Stamina.
- [Dying](Browse/rule/health/dying.md): Stamina below 0 — you keep acting, but
  you're bleeding, and you die at the negative of your winded value.
- Spend a [Recovery](Browse/rule/health/recoveries.md) to heal
  ([Catch Breath](Browse/feature/common/maneuvers/catch-breath.md) maneuver);
  a [respite](Browse/rule/resource/respite.md) restores everything.

## Director Quick Numbers

- **Hero encounter strength** = 4 + 2 × level
  ([encounter building](Read/bestiary/monster-basics.md)).
- [Encounter Value (EV)](Browse/rule/monster/encounter-value.md): a creature's
  budget cost; [minions](Browse/rule/organization/minion.md) are bought 4 at a time.
- [Hero tokens](Browse/rule/resource/hero-token.md) ·
  [Victories](Browse/rule/resource/victories.md) (every 2 average Victories ≈ one
  extra hero of encounter strength).
